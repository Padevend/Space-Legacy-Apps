# Sources institutionnelles autorisées

Ce fichier liste les sources externes autorisées pour `space-research`. **Aucune autre source n'est acceptée**, même si elle paraît crédible. WebFetch sur une source hors liste doit être refusé.

## Sources primaires NASA

| Nom | Domaine | Rôle |
|---|---|---|
| NASA (portail principal) | `nasa.gov` | Communiqués officiels, pages mission |
| NASA Science | `science.nasa.gov` | Pages scientifiques détaillées par mission |
| NASA/JPL | `jpl.nasa.gov`, `mars.nasa.gov` | Missions interplanétaires, rovers, atterrisseurs |
| NASA NSSDCA | `nssdc.gsfc.nasa.gov` | Catalogue d'archives scientifiques, fiches de missions historiques |
| NASA Planetary Data System | `pds.nasa.gov` | Données planétaires brutes et archivées |
| NASA Image and Video Library | `images.nasa.gov` | Médias officiels avec crédits et métadonnées |
| NASA Technical Reports Server | `ntrs.nasa.gov` | Rapports techniques |

## Sources institutionnelles complémentaires

Acceptées uniquement si l'information n'est pas disponible sur une source NASA :

| Nom | Domaine | Rôle |
|---|---|---|
| ESA (Agence spatiale européenne) | `esa.int` | Missions conjointes ou données européennes |
| USGS Astrogeology | `astrogeology.usgs.gov` | Cartographie et sélénographie |
| Smithsonian National Air and Space Museum | `airandspace.si.edu` | Contexte historique, objets exposés |
| Lunar and Planetary Institute | `lpi.usra.edu` | Documents scientifiques historiques |

## Sources explicitement interdites

- Wikipedia (quelle que soit la langue).
- Blogs personnels et plateformes de type Medium, Substack.
- Agrégateurs d'actualité (space.com, sciencealert, phys.org) sauf comme piste vers une source primaire.
- Réseaux sociaux.
- Forums (Reddit, Quora).
- Contenus générés par d'autres IA.

## Règles d'usage

1. Toujours noter la date d'accès (`YYYY-MM-DD`).
2. Toujours citer l'URL complète, pas uniquement le domaine.
3. Si une information figure à la fois dans un JSON du projet et sur une source listée, le JSON du projet reste la source citée. La source externe sert de confirmation secondaire.
4. Une incohérence entre JSON et source NASA doit être signalée à l'utilisateur, pas résolue silencieusement.

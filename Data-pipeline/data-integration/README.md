# Stage 3: Data Integration (`data-integration`)

The `data-integration` module is the 3rd and final stage of the **SPACE LEGACY** data pipeline. It ingests bulk datasets generated by `data-processing`, deduplicates entities across spacecraft, enforces strict foreign-key topological order, and exports a standalone PostgreSQL seeding script (`results/seed.sql`) or seeds directly into a live database.

---

## Core Principles & Guarantees

1. **Topological Dependency Ordering**:
   - Seeded in strict 4-level topological dependency order:
     - **Level 0 (Independent core)**: `celestial_bodies` (`CelestialBody`)
     - **Level 1 (Direct dependencies)**: `machines` (`Machine` $\rightarrow$ `celestial_bodies.id`)
     - **Level 2 (First-tier associations)**: `machine_sources` (`MachineSource`), `machine_images` (`MachineImage`)
     - **Level 3 (Second-tier associations)**: `machine_facts` (`MachineFact`), `machine_events` (`MachineEvent`)

2. **Deduplication by Primary Key**:
   - Celestial bodies (Moon, Mars, Ceres, 433 Eros, Deep Space) shared across spacecraft are seamlessly deduplicated by primary key (`id`).

3. **Conflict Resolution & Idempotency**:
   - Direct database inserts use `INSERT ... ON CONFLICT ("id") DO NOTHING`.
   - Standalone `seed.sql` script includes explicit transaction blocks (`BEGIN; ... COMMIT;`) and conflict clauses.

4. **Zero Missing Data**:
   - All 13 cataloged machines and their associated sources, facts, events, and images are fully populated without NULLs on key fields.

---

## Output SQL Script (`results/seed.sql`)

Generates a standalone, self-contained SQL script containing over 2,000 verified NASA records:
- 5 Celestial Bodies
- 13 Machines
- ~644 Machine Sources
- 260 Machine Images
- ~725 Machine Facts
- ~426 Machine Events

### Direct Seeding

```bash
# Generate SQL seed file without database connection
python3 data-integration/main.py --sql-only

# Dry-run validation of data structures
python3 data-integration/main.py --dry-run

# Live database seeding (requires configured PostgreSQL credentials in .env)
python3 data-integration/main.py
```

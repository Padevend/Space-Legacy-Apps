# Stage 1: Data Ingestion (`data-ingestion`)

The `data-ingestion` module is the 1st stage of the **SPACE LEGACY** data pipeline. It crawls authoritative space agency websites (NASA Science, NASA NSSDC, NASA JPL) to collect raw historical, technical, and media information for targeted spacecraft, landers, rovers, and scientific packages.

---

## Architecture & Operation

```
data-ingestion/
├── resources.json      # Target URLs, keyword scrapers, and output filenames
├── main.py             # Asynchronous crawling engine powered by crawl4ai
└── results/
    ├── json/           # Primary output: raw JSON datasets consumed by Stage 2
    │   ├── apollo_lunar_modules.json
    │   ├── mars_pathfinder.json
    │   └── ... (13 raw spacecraft datasets)
    ├── markdown/       # Concatenated raw markdown content
    └── logs/           # Crawling execution logs
```

### Crawling Engine (`main.py`)
- **Technology**: Built on `crawl4ai` using an asynchronous headless browser (`AsyncWebCrawler`, `BrowserConfig`).
- **Deep Crawling Strategy**: Uses `BestFirstCrawlingStrategy` with `KeywordRelevanceScorer`.
- **Search Boundaries**:
  - `MAX_DEPTH = 3`: Maximum link depth from the seed URL.
  - `MAX_PAGES = 50`: Maximum successful pages fetched per spacecraft to avoid web crawler runaway.
- **Scoring**: Ranks pages dynamically based on relevance to target keywords defined in `resources.json`.

---

## Configuration (`resources.json`)

Each entry defines:
- `link`: Authoritative seed URL (e.g. `https://nssdc.gsfc.nasa.gov/nmc/spacecraft/display.action?id=1969-059C`).
- `target`: Keyword relevance terms (e.g. `["Apollo", "Lunar Module", "Moon", "spacecraft", "lunar landing"]`).
- `output_name`: Canonical base filename (e.g. `apollo_lunar_modules`).

```json
    "max_depth": 3,

    "completed_at": "2026-11-14T12:05:00Z"

  ]
}
```

## Execution

```bash
cd data-ingestion
python3 main.py
```
Outputs are written to `results/json/*.json` and directly consumed by Stage 2 (`data-processing`).
